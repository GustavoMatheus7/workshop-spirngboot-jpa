# Spring Boot - Web Services

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma API REST utilizando Java e Spring Boot, desenvolvido durante os estudos de programação com base no curso do Nelio Alves.

A aplicação simula um sistema de pedidos de uma loja virtual, com funcionalidades para gerenciar usuários, produtos, categorias, pedidos, itens de pedidos e pagamentos.

O objetivo do projeto é praticar o desenvolvimento de aplicações back-end, a criação de APIs REST e a persistência de dados em um banco de dados relacional.

## Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Spring Boot** — criação e configuração da aplicação.
- **Spring Data JPA** — persistência e acesso aos dados.
- **Hibernate** — mapeamento objeto-relacional (ORM).
- **Maven** — gerenciamento de dependências e construção do projeto.
- **Banco de dados relacional** — armazenamento das informações.

## Como executar o projeto

1. Instale o Java compatível com a versão utilizada no projeto.
2. Instale uma IDE, como IntelliJ IDEA, ou utilize outra ferramenta de sua preferência.
3. Configure o banco de dados conforme as propriedades da aplicação.
4. Abra o projeto na IDE e aguarde o carregamento das dependências Maven.
5. Execute a classe principal `CourseApplication`.
6. Utilize uma ferramenta como Postman para testar os endpoints da API.

## Objetivo de aprendizagem

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento back-end com Java e Spring Boot, permitindo praticar conceitos de orientação a objetos, APIs REST, persistência de dados, arquitetura em camadas e tratamento de exceções.
